# Make_YT_Shorts_Invis_For_Android
A lightweight Android app that wraps YouTube in a browser view with one job: strip out all Shorts content, but still give you the expirience of watching in a app and not the browser.

What it is:

This is not a full YouTube client. 

It loads YouTube's standard URL (the same as opening it in your phone's browser) and removes every trace of Shorts, so you can browse, search, and watch without the clutter.

So it's not:

A replacement for the official YouTube app,
A standalone video player 
or Ad-free (it's still just YouTube in a wrapper)

# Configuring your phone
1. Open the Settings app on your Android device.
2. Scroll to the very bottom and tap About phone (or About device).
3. Look for the Build number. (Note: If you have a Samsung device, you must first tap Software information to find the Build number).
4. Tap the Build number exactly 7 times in quick succession. 
5. A toast message will appear saying "You are now a developer!"Enter your phone's lock screen PIN, password, or pattern when prompted to confirm.

After that

6. Go back to the main Settings menu.
7. Navigate to System (On some phones like Xiaomi/POCO, this might be under Additional settings).
8. Tap Developer options.Scroll down to the Debugging section and toggle the switch for USB debugging to the ON position.
9. When the "Allow USB debugging?" prompt appears, tap OK or Allow


# Important Security Note
Leaving USB debugging enabled can pose a security risk, as it allows connected computers to access deep system data or bypass lock-screen commands. 
It is highly recommended to toggle the USB debugging switch OFF when you are done installing the app.


# Getting the app
Prerequisites

Android Studio installed and
USB debugging enabled on your phone

Steps

1. Open the NoShorts folder in Android Studio
2. Wait for the project to finish loading and syncing
3. In the top menu, go to Build → Compile 'NoShorts.app.main' — this confirms everything is set up correctly
4. Connect your phone to your computer via USB
5. Press Run — Android Studio will install and launch the app on your phone
